# 时间戳转换实施计划

**目标：** 新增 TABBOX.TIME(timestamp, unit)，默认秒、ms 表示毫秒，返回北京时间 yyyy-MM-dd HH:mm:ss 文本。

**已确认设计：** 用户已明确同意上述接口及 README 更新。沿用普通 JavaScript 和 JSON 命名空间，不引入依赖。保持现有 6 文件安装方式。

**输入约定：** 接受安全整数及整数字符串，支持零和负时间戳；空输入、非整数、无效单位及超出 0001–9999 年范围时返回 #TIME! 说明文本。毫秒的小数秒不显示。北京时间固定 UTC+8。

## 实施与验证

1. 编写 tests/json-time.test.cjs，覆盖单位换算、空输入误转纪元、范围溢出和多函数注册重试；先运行确认新增接口缺失导致失败。
2. 修改 js/functions.js、functions.json、main.js、scripts/build.cjs；逐项注册，失败重试不重复注册已成功函数，声明与构建一致。
3. 更新原有自行编写的注册验证、测试入口及 README 示例，执行本项目自行编写的验证和构建；验证在非北京时间环境仍返回 UTC+8。
4. 请求独立只读审查，处理确定缺陷后提交并同步 GitHub。真实 WPS 公式求值仍需客户端验证。

## 关注风险

1. 秒与毫秒不自动猜测，避免转换出错误日期。
2. 空单元格、布尔值与无效文本不能转成 1970 年。
3. 年份边界和 UTC+8 偏移不能溢出约定格式。
4. 新函数注册失败后不能重复注册 GET，也不能报告全部成功。
5. 安装后的 6 个静态文件需包含新声明和实现，不增加运行环境要求。
